## Historical implementation and model policy

`MINISGL_MEGAMOE_PAYLOAD_MODE=all_push` selects the SF-units device kernel,
concurrent-SF router and matching eight-row native TMA descriptor. All maintained
Python/native/CUDA selectors use `all_push`/`kAllPush`. The distinct
`GateTopkAllPushKernel` wrapper prevents a shared-memory setup flag collision
with the plain router. Pull keeps its existing arithmetic and device path.

Model decode requests a fixed1,024-row FFN-rank pool, rounded to1,152 physical
rows by existing384-row alignment, independent of input size. Padded routed rows must fit; receive-bank and top-k/intermediate
storage add overhead. Explicit pull prefill uses a separate allocation sized for
its configured limit. No batch chunker is maintained. Decode alternates two
allocations per lane. The current candidate retires outputs, releases PDL, then
uses one CTA to clear the next internal bank. Destination-local epochs gate reuse;
no per-call peer barriers or preparation streams. The next Qwen3 norm acquires
output readiness separately from reset. Actual hidden latency remains a trace
and full-model performance gate.

Ordinary kernel timing retains producer+selector+MegaMoE, excludes preparation,
and averages every rank-local call. Detailed instrumentation is separate. The
harness initializes physical timing events before warmups. All-rank captures
retain device identity, three readiness windows and raw marker evidence.
